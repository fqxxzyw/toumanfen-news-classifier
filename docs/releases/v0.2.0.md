# v0.2.0 · FastText 完整流程与 BERT 数据加载

发布日期：2026-10-18。上一版本：[v0.1.0](https://github.com/fqxxzyw/toumanfen-news-classifier/releases/tag/v0.1.0)。

本版将 FastText 字符/词语分类、自动调参、四模型评估、预测 API 和页面纳入项目，
新增 BERT 配置、数据读取、批次分词与 DataLoader。BERT 微调训练与评估尚未实现。

提供源码、数据和小型配置，不提供训练模型或大型预训练权重附件。
GitHub 的 Source code (zip/tar.gz) 对应固定标签 v0.2.0。

## 一、获取与运行

Windows Anaconda Prompt / CMD：

```bat
git clone --branch v0.2.0 --depth 1 https://github.com/fqxxzyw/toumanfen-news-classifier.git
cd toumanfen-news-classifier
conda activate toumanfen
cd 03_fasttext
python -m pip install -r requirements.txt
```

新环境可先创建 Python 3.10 环境；已有环境无需重复创建。

从 03_fasttext 依次执行：

```bat
python src/preprocess.py
python src/train.py
python src/evaluate.py
```

已有 processed 数据可跳过预处理，已有模型可跳过训练。
预处理会覆盖六份 char/word 的 train/dev/test 文件；训练会覆盖四个同名模型，
包含两个基础训练与两个 300 秒自动调参搜索，整体耗时还包括最终训练和保存。

已有模型放在 03_fasttext/models：fasttext_char.bin、fasttext_word.bin、
fasttext_char_autotune.bin、fasttext_word_autotune.bin。模型不包含在 Release 附件中。

### API 与页面

两个终端都进入 03_fasttext，并保持运行：

```bat
python src/api.py
```

```bat
python -m streamlit run src/app.py
```

打开 http://localhost:8501。API 默认加载字符自动调参模型。
GET /health 用于检查服务；POST http://127.0.0.1:8000/predict 接收：

```json
{"text":"郑州马拉松今日正式开跑"}
```

返回 label、probability。单条预测脚本为 `python src/predictor.py`。
字符模型使用 char 预处理，词语模型使用 word。

## 三、实际验证结果

| 模型 | 验证数据 | dev 准确率 |
| --- | --- | ---: |
| fasttext_char | dev_char.txt | 87.17% |
| fasttext_word | dev_word.txt | 89.90% |
| fasttext_char_autotune | dev_char.txt | 91.43% |
| fasttext_word_autotune | dev_word.txt | 91.55% |

每个模型评估 10,000 条。dev 同时用于调参，这些成绩不能当作最终独立 test 指标。
发布整理没有重新执行全量训练或覆盖模型。

- 临时样本验证 char/word 预处理、覆盖写入、两模型训练与真实保存。
- 参数解析检查确认 autotuneDuration 和训练/验证路径正确，没有再次启动 300 秒搜索。
- 真实单条预测返回类别与概率；API 和 Streamlit 健康检查通过。
- 发布复查使用 AppTest 和真实 Flask test_client，验证按钮、预测响应和页面 JSON 显示，传输层注入本地客户端。
- BERT 读取 180,000 条训练数据，首个非随机 batch 的 input_ids=(16,26)、labels=(16,)。
- 新增阶段共 9 个 Python 文件语法检查通过。

具体环境与限制见 [验证记录](https://github.com/fqxxzyw/toumanfen-news-classifier/blob/v0.2.0/docs/VALIDATION.md)。

## 四、今日解决的问题

| 问题 | 修复 |
| --- | --- |
| 输出目录当作文件打开 | 补齐输出文件名 |
| 修改格式后旧数据仍存在 | 追加 a 改为覆盖 w |
| fastText 不接受 WindowsPath | 使用字符串路径 |
| 中文绝对路径打不开训练数据或模型 | 改用不含中文的相对路径 |
| 没有接收训练模型，误用了 cffi.model | 接收 train_supervised 返回值再保存 |
| autotunDuration 拼写错误 | 改为 autotuneDuration |
| Config 没有实例属性 | 使用 Config() |
| 分类报告收到标签序列 | 提取每条 Top-1 标签字符串 |
| NumPy 2 单条预测 copy=False 错误 | 使用 fastText 批量预测接口 |
| 预测预处理参数 model 拼错 | 改为 mode，字符模型指定 char |
| 普通 Python 启动 Streamlit 无网页 | 使用 python -m streamlit run |
| BERT 函数定义无参数但传了路径 | load_news_data 接收并读取 file_path |
| news_path/max_len 不存在 | 具体路径参数及 max_length 配置 |
| 分词器路径随工作目录变化 | 使用 conf.pretrained_model_path |

当前 Windows fastText 请从仓库根目录、03_fasttext 或其 src 运行，使相对路径不含中文。

## 五、BERT 当前运行方式

从仓库根目录执行：

```bat
cd 04_bert
python -m pip install -r requirements.txt
python src/data.py
```

入口只打印类别并创建 DataLoader，不微调。默认 batch_size=16、max_length=64、num_workers=0。
动态 padding 补到当前批次最长文本，所以批次长度不一定等于 64。

仓库保留 config、tokenizer 和 vocab，数据加载不需要大权重。
后续微调需自行准备与 bert-base-chinese 配置兼容的 PyTorch 权重，放入预训练目录。
本地 .bin、.h5、.msgpack 权重保留，不上传，也不需要同时使用全部框架权重。
