# v0.1.0 · 新闻分类本地演示初版

发布日期：2026-10-17。

## 当前版本

完成中文新闻标题十分类的六步流程：数据分析 → 清洗分词 → TF-IDF / 随机森林训练 → 独立验证 → Flask API → Streamlit 页面。

## 今日完成步骤与进度

1. **数据分析：已完成实现。** 检查原始字段、类别、长度分布及跨集合重复文本。
2. **清洗与分词：已完成实现。** 处理缺失值、HTML、不可见字符和空白；分词后最多保留 30 个词，导出三个 CSV。
3. **训练：已完成实现与小样本验证。** 保持稀疏 TF-IDF，默认 100 棵树、每批 5 棵、2 个工作线程，使用进度条显示训练和预测；先划分再拟合词表。
4. **独立验证：已补全实现。** 在 dev 集计算宏平均指标，导出预测 CSV 与 JSON 指标。
5. **API：已完成实现。** POST `/predict` 返回分类标签，校验请求对象和非空文本，默认本地端口 8001。
6. **网页：已完成实现。** Streamlit 提交新闻、中文结果、加载状态及错误提示，默认端口 8501。
7. **工程整理：已完成。** 入口按 01～06 编号，保留共用模块；调整导入、路径和启动提示；重写 README 为从零开始的操作与开发指南。
8. **个人练习：仅本地。** 原练习和 HTTP 测试演示移入忽略目录；后续练习从现有代码复制，使用独立生成物和接口端口，不上传 GitHub 或 Release。

## 模型与版本关系

仓库不提交大型模型和清洗后的 CSV。本次 Release 提供源码；大型模型附件上传超时，已清理未完成的附件。新电脑首次使用可按 README 运行步骤 2、3，或者自行复制已有的配套模型。本机原模型和本地预习副本保持不变，没有重新训练。

本机保留 `dist/demo-models-v0.1.0.zip` 及 SHA-256 校验值。归档中的模型保存时间早于本轮目录整理，保留用于恢复已有演示。它们不是本轮重新训练的模型；不要将其分数作为当前训练代码的最终基准。两个 `.pkl` 必须配套使用，建议在不同依赖环境中重新训练。

## 验证与实际进度

验证记录见 [VALIDATION.md](../VALIDATION.md)。小样本试跑用于确认训练、保存和预测链路可用，不替代全量训练或最终测试集评估。

**整体进度：本地学习和端到端演示已打通；模型基准和生产化尚未完成。** 本版不承诺生产服务能力，不支持森林训练的磁盘断点续训。原始数据的重复文本检查结果需要在后续严谨评估时处理。
