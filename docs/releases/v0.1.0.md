# v0.1.0 · 中文新闻标题分类：随机森林基线与本地演示

发布日期：2026-10-17。

这是中文新闻标题十分类项目的首个整理版本。输入一条中文新闻标题，经过 jieba 分词、TF-IDF 特征转换和随机森林预测，返回财经、体育、教育等十个类别之一；可通过 Flask API 或 Streamlit 页面使用。

**本版本提供源码和原始数据，不提供训练好的模型附件。已有配套模型时，可以直接启动演示，无需重新训练。**

## 一、快速运行

### 1. 获取代码与安装环境

可以下载本页 Assets 中 GitHub 自动生成的 **Source code (zip)**，解压后进入项目根目录。也可以直接获取本次标签对应的源码：

```bat
git clone --branch v0.1.0 --depth 1 https://github.com/fqxxzyw/toumanfen-news-classifier.git
cd toumanfen-news-classifier
```

以下环境命令在 Windows Anaconda Prompt / CMD 中执行；已有 `toumanfen` 环境时跳过创建：

```bat
conda create -n toumanfen python=3.10 -y
conda activate toumanfen
python -m pip install -r requirements.txt
```

### 2. 已有模型：直接启动页面

将同一次训练产生的两个文件放到项目根目录的 `model/`：

```text
model/
├── rf_model.pkl
└── tfidf_model.pkl
```

同时保留 `data/class.txt` 的类别顺序。API 启动预测不需要重新生成 CSV，也不需要运行训练脚本。

**第一个终端：启动分类接口。** 在项目根目录执行并保持运行：

```bat
conda activate toumanfen
python src/05_predict_api.py
```

接口为 `http://127.0.0.1:8001/predict`，等待模型加载、服务启动。

**第二个终端：启动网页。** 进入同一项目根目录后执行：

```bat
conda activate toumanfen
python -m streamlit run src/06_app.py
```

打开 **http://localhost:8501**，输入标题，点击“开始分类”。两个终端都需要保持运行。

如果终端已经位于 `src/`，两条启动命令分别改成 `python 05_predict_api.py` 和 `python -m streamlit run 06_app.py`，不要再添加 `src/` 前缀。

### 3. 没有模型：按步骤准备

源码中的 `data/` 已包含原始训练、验证、测试 TXT、类别表和停用词。需要自己生成 CSV 和模型时，按以下顺序执行：

```bat
python src/01_eda.py
python src/02_data_process.py
python src/03_train.py
python src/04_evaluate.py
```

训练可能耗时较长，完成后再启动上面的 API 和网页。已有 CSV 或模型时，可以跳过相应生成步骤；不要为了打开页面反复训练。

## 二、本版本包含的功能与代码

| 步骤 | 文件 | 做什么 | 核心函数或执行入口 | 输出 |
| --- | --- | --- | --- | --- |
| 01 | `src/01_eda.py` | 分析数量、标签、长度、重复和跨集合交集 | `load_classes`、`load_dataset`、`analyze_split`、绘图函数、`check_split_overlap`、`main` | EDA 图表与 JSON |

| 03 | `src/03_train.py` | 划分文本、拟合 TF-IDF、训练森林并内部评估 | `positive_int`、`main` | 两个配套模型及控制台指标 |
| 04 | `src/04_evaluate.py` | 加载模型，在独立 dev 集评估 | 顶层脚本，调用 `predict_batches` 和分类指标函数 | 预测对照 CSV、指标 JSON |
| 05 | `src/05_predict_api.py` | 接收 POST JSON、校验文本、调用预测 | `predict_api` | `result.label` JSON |

共用模块：

- `src/config.py`：`Config.__init__` 根据脚本位置构造数据、模型和报告路径。

- `src/prediction.py`：导入时加载模型，`predict_fun` 对单条文本分词、转换特征并映射类别。

完整的 25 个函数与方法的参数、执行过程、返回值和调用关系，见 [完整开发教程与函数索引](https://github.com/fqxxzyw/toumanfen-news-classifier/blob/main/README.md)。

## 三、数据、类别与模型约定

### 原始数据

使用 THUCNews 20 万条新闻标题子集：train 180000 条、dev 10000 条、test 10000 条。TXT 为 UTF-8、无表头，每行由标题、实际 Tab 制表符和整数标签组成。清洗后数量以实际输出为准。

| 标签 | 英文类别 | 中文 |
| --- | --- | --- |
| 0 | finance | 财经 |
| 1 | realty | 房产 |
| 2 | stocks | 股票 |
| 3 | education | 教育 |
| 4 | science | 科技 |
| 5 | society | 社会 |
| 6 | politics | 时政 |
| 7 | sports | 体育 |
| 8 | game | 游戏 |
| 9 | entertainment | 娱乐 |

清洗输出统一为 `text,label,words` 三列，其中 `words` 是最多 30 个词的空格分隔文本。完整的清洗标题保留在 `text`。

### 训练方式

- 从 `train.csv` 分出 80% 训练部分和 20% 内部评估部分，按类别分层，随机种子为 42。
- TF-IDF 只在训练部分拟合，评估和在线预测使用保存的向量器转换。
- 保持稀疏 `float32` 特征，避免整个矩阵转成稠密数组。
- 默认训练 100 棵树，每批增加 5 棵，使用 2 个并行工作单元；每批完成后更新进度。
- 默认每 2000 条样本分批预测。
- 使用准确率、宏平均精确率、召回率和 F1，不使用二分类默认的 `average='binary'`。

随机森林按“树”分批，每批仍使用同一训练部分；不属于按样本块的 `partial_fit`，也没有磁盘断点续训。分批显示进度不等于模型已经压缩。

### 验证集与测试集

第三步的内部 20% 不是磁盘上的 `test.csv`。第四步读取独立的 `dev.csv`，输出 dev 指标；本版没有独立的最终 test 评估入口。

两个 `.pkl` 必须配套使用，类别文件顺序也必须一致。版本号是代码版本，不代表已有模型在本次发布时重新训练；本次整理保留了原有模型。

## 五、HTTP 请求与响应示例

分类接口只接受 **POST `/predict`**，Content-Type 为 `application/json`：

```json
{"text": "中国队在比赛中夺得冠军"}
```

成功响应示例，具体类别以实际预测为准：

```json
{
  "result": {
    "text": "中国队在比赛中夺得冠军",
    "label": "sports"
  }
}
```

缺少文本、文本不是字符串或只有空白，返回 HTTP 400 和 `{"error":"Invalid data"}`。直接在浏览器地址栏打开 `/predict` 会发出 GET，通常得到 405；该接口没有定义 `/` 首页路由。

网页显示中文类别，对空输入、连接失败、超时、HTTP 错误或响应结构异常给出提示。接口目前没有返回 Top-K、概率或模型版本字段。
