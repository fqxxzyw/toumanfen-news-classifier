## 更新内容

### BERT

- 修复类别数和早停状态初始化、标签映射、设备移动、DataLoader 参数及反向传播。
- 使用验证集宏平均 F1 保存完整最优模型、tokenizer 和 metadata.json。
- 修复测试脚本中模型类型错用、配置对象误当文件路径、评估参数与返回值读取错误。
- 修复单条预测的 argmax 解包问题，返回类别 ID、英文类别和最大 softmax 概率。
- 新增 Flask /health、/predict 和 Streamlit 页面，支持示例、中文类别、分数、断连与超时提示。
- 训练、数据、指标和预测代码补充详细中文注释。

### DeepSeek / 大肥鱼

- 新增 05_LLM 阶段的配置、新闻数据、十分类提示词和依赖文件。
- 完成 DeepSeekClient：单条命令、交互输入、可选 JSONL 保存，复用同一分类逻辑。
- 请求 JSON 结果并检查类别范围、理由和输出截断，提供可读的鉴权、余额、网络与限流错误。
- 新增蓝白海洋主题页面、本地鲸鱼娘插画、示例填充、分类理由与会话记录导出。
- 支持本地 .env、环境变量及页面会话密钥；源码只提供空值 .env.example。

## 获取源码

在本 Release 页的 **Assets → Source code (zip/tar.gz)** 下载固定版本，或执行：

```powershell
git clone --branch v0.3.0 --depth 1 https://github.com/fqxxzyw/toumanfen-news-classifier.git
cd toumanfen-news-classifier
conda activate toumanfen
```

新环境建议使用 Python 3.10。各阶段依赖按对应 requirements.txt 安装，不包含运行中的后台服务。

## BERT 运行

进入 04_bert，准备本地预训练权重后可执行训练：

```powershell
cd 04_bert
python -m pip install -r requirements.txt
python src/train.py
```

已有完整 models/best_model 时可直接运行测试或预测：

```powershell
python src/test_model.py
python src/predictor.py
```

两个终端均位于 04_bert，分别启动 API 与页面：

```powershell
python src/api.py
```

```powershell
python -m streamlit run src/app.py --server.address 127.0.0.1 --server.port 8501
```

API：`POST http://127.0.0.1:8000/predict`，请求体 `{"text":"球队在总决赛中夺冠"}`；页面：<http://127.0.0.1:8501>。
训练参数在 src/config.py 修改，当前训练入口不解析命令行超参数。FastText 与 BERT 默认端口重复，切换项目前先停止旧服务。

## DeepSeek 命令行与主题页面

从仓库根目录进入 05_LLM：

```powershell
cd 05_LLM
python -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

仅在本机编辑 .env，填写自己的 **DEEPSEEK_API_KEY**；也可在页面侧栏输入，不需要把密钥提供给其他人。

```powershell
# 交互模式，输入 q 退出
python src/deepseek_client.py

# 单条分类，--save 为可选保存开关
python src/deepseek_client.py --text "股票指数上涨，多只个股涨停" --save

# 大肥鱼主题页面
python -m streamlit run src/app.py --server.address 127.0.0.1 --server.port 8502
```

页面：<http://127.0.0.1:8502>。返回 category 和 reason，不把模型生成的文字解释当作校准后的置信度。

## 发布范围与限制

- 提供源码、新闻数据、依赖、小型配置、主题插画与空值密钥样例；不附带 .env、真实密钥、训练模型或大型预训练权重。
- BERT 推理需自行提供整个 best_model 目录，包括权重、config.json、tokenizer 和 metadata.json；不需要再携带原始预训练模型。
- DeepSeek 验证使用模拟响应，真实联网分类仍需有效密钥与账户额度；不报告尚未实测的 LLM 准确率。
- 尚未重新执行完整 BERT 训练或全量 test 基准，不支持优化器状态恢复、断点续训；生产部署和负载测试尚未完成。
- 旧版 v0.1.0、v0.2.0 标签和发布记录保留，本地密钥与模型文件不被删除或覆盖。
