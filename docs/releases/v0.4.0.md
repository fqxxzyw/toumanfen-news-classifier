# v0.4.0 · 模型蒸馏与剪枝实验

发布日期：2026-10-25。上一版本：[v0.3.0](https://github.com/fqxxzyw/toumanfen-news-classifier/releases/tag/v0.3.0)。本版本记录当前实验代码，未将小样本检查作为全量模型质量或加速成绩。

## 本次更新

- `07_model_distillation`：BERT Teacher、离线 logits/CLS 特征缓存、BiLSTM Student、硬标签交叉熵/软标签 KL/特征 MSE 加权损失、批训练进度条、Dev Macro-F1 选优与早停、预测入口。
- Teacher 缓存使用正确的 `input_ids`、`hidden_states` 与配置路径，按原始样本下标重排；Student 注释解释各层用途、张量形状和掩码池化过程。
- `08_model_prune`：对 BERT 各层 Query Linear 权重执行全局 L1 非结构化剪枝，默认比例 30%；比较剪枝前后指标，恢复微调，再固化权重并保存模型和分词器。
- 纳入 v0.3.0 之后的 LLM 分类评估、Flask API、批量处理改进，以及 CPU 动态 INT8 量化、权重恢复、质量评估和延迟比较入口。
- 上传 07、08 的原始训练、验证、测试和类别文件。`预习/`、各阶段 `models/`、Teacher 缓存和剪枝运行输出均不随源码发布。

## 蒸馏与剪枝入口

以下为运行指引，本次发布检查没有执行这些完整训练命令。使用已有 `toumanfen` 环境；新环境需准备与设备适配的 PyTorch，以及 `transformers`、`scikit-learn`、`tqdm`。07、08 尚无独立依赖锁定文件。

蒸馏：在 `07_model_distillation/models/teacher/` 放置完整的已微调 BERT 分类模型和分词器，核对 `src/config.py` 的类别数、数据路径和训练参数。从仓库根目录运行：

```powershell
python 07_model_distillation/src/cache_teacher.py
python 07_model_distillation/src/train_distill.py
python 07_model_distillation/src/predict.py
```

缓存写入 `07_model_distillation/cache/`，最佳 Student 权重写入 `models/student/best_student.pt`。训练数据内容或顺序、Tokenizer、最大长度或 Teacher 变更后，应重新生成缓存。当前 Student 预测入口仍会调用 Teacher 加载函数，因此需要保留本地 Teacher 文件。

剪枝：在 `08_model_prune/models/original/` 放置完整的已微调 BERT 分类模型和分词器，核对 `src/config.py`。从仓库根目录运行：

```powershell
python 08_model_prune/src/train_prune.py
python 08_model_prune/src/predict.py
```

训练脚本会执行剪枝前评估、剪枝后评估、恢复微调及最终评估，结果保存到 `08_model_prune/models/pruned/`。`evaluate.py` 提供供训练流程调用的评估函数，没有独立命令行评估入口。

## 实际验证与限制

- 07、08 全部 16 个 Python 文件语法检查通过。
- 小型 Student 前向、三项蒸馏损失组合及反向传播通过。
- 剪枝评估函数在已知预测的合成样本上返回预期指标。
- 小型 Query 权重剪枝达到 30% 稀疏率，固化剪枝后输出不变。
- 没有执行完整蒸馏、剪枝恢复训练、全量测试集或真实推理性能基准。量化历史成绩见 [2026-10-21 进度](../progress/2026-10-21.md)，不代表本次重新测得。
- 非结构化剪枝将部分权重置零，不能据此认定常规稠密推理变快或权重文件变小。
- 已知问题：`cal_model_zero_ratio` 的子模块判断对象需要修正；当前训练流程使用 `calculate_sparsity` 统计 Query 稀疏率，不使用前者。

详细证据见 [验证记录](../VALIDATION.md)，变更记录见 [CHANGELOG](../../CHANGELOG.md)。
