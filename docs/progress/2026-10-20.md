## 今日解决的问题与知识点

| 问题 | 原因与处理 |
| --- | --- |
| best_f1、早停计数器报黄 | 变量读取前必须赋值；在 epoch 循环外初始化，避免每轮重置历史状态 |
| num_classes 未定义 | 从 len(class_list) 获取类别数，决定分类头输出维度 |
| open() 收到 Config 对象 | build_dataloader 首个参数需要文件路径；使用 config.test_path，配置通过 config= 单独传入 |
| 模型出现 UNEXPECTED/MISSING 提示 | 测试脚本用 ALBERT 类加载 BERT；改用 AutoModelForSequenceClassification 根据配置选择模型结构 |
| evaluate 参数与返回值不匹配 | 补传类别名称列表；返回值是 (acc, precision, recall, f1, report)，按固定顺序解包 |
| argmax 无法解包为分数和类别 | argmax 只返回下标；使用 torch.max(prob, dim=1) 同时取得最大概率与类别 ID |
| 分享模型是否要带预训练目录 | 完整 best_model 已保存微调后的模型与 tokenizer，推理时提供整个目录即可；不能只发单个权重文件 |
| 普通 Python 运行 app.py 没有页面 | Streamlit 页面用 python -m streamlit run src/app.py 启动 |
| DeepSeek 返回值不可直接信任 | 请求 JSON 格式后仍在本地检查类别范围、理由、空结果与截断状态 |
