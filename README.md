# 投满分项目：按学习阶段整理

项目分为四个业务目录，Git 和 IDE 隐藏目录保留在根目录。

| 目录 | 内容 |
| --- | --- |
| [01_data](01_data/README.md) | 原始数据分析、文本清洗、jieba 分词、TXT 转 CSV |
| [02_rf](02_rf/README.md) | 原有随机森林完整项目：预处理、TF-IDF、训练、评估、接口、页面及已有模型 |
| [03_fasttext](03_fasttext/) | 现有 FastText 数据和代码 |
| [预习](预习/) | 保持原样的独立练习目录 |

`01_data/src/01_eda.py`、`01_data/src/02_data_process.py` 从
`02_rf/src/` 原样复制。`01_data/data/` 也是现有数据的副本，包含原始 TXT、
类别表、停用词和已有 CSV；本次没有运行脚本或重新生成数据、模型。

原根目录的 `src/`、`data/`、`models/`、`artifacts/`、`dist/`、`docs/`
及原 README、依赖、版本和更新记录统一归入 `02_rf/`，内部相对结构保持不变。

阅读随机森林原有教程或以后执行其中的命令时，先进入 `02_rf`；
仅做数据处理时进入 `01_data`。两个目录中的脚本都以自身位置定位数据，
各自读取和写入各自的 `data/`。

本次只做文件复制、移动和说明整理，没有执行数据分析、预处理、训练或预测。
没有修改 Git 元数据、`.gitignore`、`.gitattributes`，也没有执行 Git 提交或推送。
